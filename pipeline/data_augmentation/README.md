# Data Augmentation

This directory contains TensorFlow image data augmentation exercises.

## Tasks

- `0-flip.py`: flip an image horizontally.
- `1-crop.py`: randomly crop an image.
- `2-rotate.py`: rotate an image 90 degrees counter-clockwise.
- `3-shear.py`: randomly shear an image.
- `4-brightness.py`: randomly change image brightness.
- `5-hue.py`: change image hue.

## Requirements

- Python 3.6
- TensorFlow 1.15
- pycodestyle 2.4
