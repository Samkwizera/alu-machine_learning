# Recurrent Neural Networks

This project implements forward propagation for recurrent neural network
architectures using NumPy.

## Files

| File | Description |
|------|-------------|
| `0-rnn_cell.py` | Implement a single cell of a simple RNN |
| `1-rnn.py` | Perform forward propagation through a simple RNN |
| `2-gru_cell.py` | Implement a gated recurrent unit cell |
| `3-lstm_cell.py` | Implement a long short-term memory cell |
| `4-deep_rnn.py` | Perform forward propagation through a deep RNN |
| `5-bi_forward.py` | Calculate a bidirectional cell's forward hidden state |
| `6-bi_backward.py` | Calculate a bidirectional cell's backward hidden state |
| `7-bi_output.py` | Calculate the outputs of a bidirectional RNN |
| `8-bi_rnn.py` | Perform forward propagation through a bidirectional RNN |

## Requirements

- Python 3.x
- NumPy
