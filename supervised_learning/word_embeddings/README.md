# Word Embeddings

This project explores techniques for representing text as numerical vectors,
from sparse frequency-based representations to trainable neural embeddings.

## Files

| File | Description |
|------|-------------|
| `0-bag_of_words.py` | Create a bag-of-words embedding matrix |
| `1-tf_idf.py` | Create a TF-IDF embedding matrix |
| `2-word2vec.py` | Create and train a Gensim Word2Vec model |
| `3-gensim_to_keras.py` | Convert Word2Vec to a trainable Keras layer |
| `4-fasttext.py` | Create and train a Gensim FastText model |
| `5-elmo` | Answer a conceptual question about training ELMo embeddings |

## Requirements

- Python 3.x
- NumPy
- scikit-learn
- Gensim
- Keras
